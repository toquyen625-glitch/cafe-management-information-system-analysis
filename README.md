# Analysis and Design of a Café Management Information System

## Project Overview

An academic Systems Analysis and Design project focused on analyzing café operations and designing an information system to support key management activities. The project involved gathering stakeholder requirements, modeling system functionality, and structuring data to represent the café's operational needs.

## Project Objectives

- Analyze café operations and identify stakeholder requirements.
- Translate business requirements into system models.
- Design a structured data model to support key café management processes.

## My Contributions

- **Requirements Elicitation:** Conducted interviews to gather stakeholder requirements and identify operational needs and potential system improvements.
- **System Modeling:** Developed Use Case models to represent system functionality and interactions based on business requirements.
- **Data Modeling:** Designed an Entity-Relationship Diagram (ERD) to represent data entities and relationships supporting café management.
- **Team Collaboration:** Collaborated with seven team members to align requirements, system models, and project deliverables.
